# BDO-AIO v2.5.0 — Native dashboard & Obsidian Gold

- Native Windows dashboard with eight pages; the classic console remains available.
- Obsidian & Gold styling with Dark (default), Night and Light themes. Preview from
  Appearance; Save settings remembers the choice without applying game changes.
- Detailed class editing, native recovery previews and GameOption profile previews.
- Atomic settings saves preserve unknown fields and reject concurrent edits.
- Failed injection-stage promotion restores the previous stage instead of losing it.
- Portable Windows regression tests and theme/layout coverage.

## Install / update

Extract the full archive into your existing BDO-AIO folder, replacing application
files. Your existing config.json, presets and assets are not shipped or overwritten
by the archive. Run START.bat; START-CLASSIC.bat opens the original console.
Python 3 and your own Black Desert installation are required for mod operations.

Save settings does not patch the game. Existing recovery confirmations and backups
remain intact. CI and UI checks do not prove in-game appearance or performance.
